 html_basic

This is my first website. I built it with only HTML.

Files:

base_index.html: a very basic page that passes the W3C validator
index.html: my home page with titles, paragraphs and a clickable image
 tweets.html: a page with one tweet and a link back to the home page

 How the pages are built:

Each page has three parts:

header: a list of links to my pages
main: the article (the page content) and the aside (a placeholder for comments later)
footer: my name and a link
