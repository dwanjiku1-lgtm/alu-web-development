 html_advanced

This is my page about the African Leadership University (ALU). I made it from a Figma design. I only used HTML, so it looks plain for now. I will add CSS in the next project.



 What I learned:

I learned how to turn a design into HTML. I also learned which tags to use, like header, main, section and footer. Putting tags inside other tags was hard at first, but it got easier. I used the W3C validator to find my mistakes.

 What is on the page:

1. The header has a logo and three links.
2. The banner has a title, some text, a button and four small items.
3. The quote part has a picture and a short quote.
4. The videos part has four videos about life at ALU.
5. The programmes part has four programmes and a button.
6. The FAQ has four questions and answers.
7. The footer has a logo and social links.
